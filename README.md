# Iot-PIR-motion-based-Intrusion-Alert-System-for-security
A low-cost IoT security device for PG / hostel rooms. It uses a NodeMCU ESP8266 and PIR sensor to detect human movement using body heat. When motion is detected, it sends a real-time push notification to the owner's phone via the Blynk IoT platform, even when the owner is away.
